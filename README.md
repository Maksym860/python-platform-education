# PyPath — інтерактивна платформа для вивчення Python

Курсова робота: «Розробка інтерактивної вебплатформи для вивчення основ програмування мовою Python
учнями 7–8 класів». Реалізовано MVP: навчальні модулі, уроки, теорія з прикладами коду, тести після
кожного уроку, REST API та адаптивний інтерфейс.

## Технології

- **Frontend:** React 18 + Vite, React Router
- **Backend:** Node.js + Express
- **База даних:** MongoDB + Mongoose
- **API:** REST
- **Стилізація:** структурований CSS (дизайн-система у `client/src/styles/global.css`)

## Структура проєкту

```
interactive-python-platform/
├── client/     # React + Vite фронтенд
├── server/     # Node.js + Express бекенд
└── docs/       # architecture.md, api.md
```

Детальніше — у `docs/architecture.md` та `docs/api.md`.

## Запуск проєкту локально

Потрібно: Node.js 18+ і MongoDB (локально запущений або хмарний, напр. MongoDB Atlas).

### 1. Backend

```bash
cd server
npm install
cp .env.example .env      # за потреби зміни MONGODB_URI
npm run seed               # заповнює базу демонстраційним контентом
npm run dev                 # запускає API на http://localhost:5000
```

### 2. Frontend

У новому терміналі:

```bash
cd client
npm install
npm run dev                 # запускає застосунок на http://localhost:5173
```

Vite-проксі вже налаштовано (`vite.config.js`), тому фронтенд звертається до `/api/**`,
а запити автоматично йдуть на `http://localhost:5000`.

Відкрий у браузері **http://localhost:5173**.

## Демонстраційний контент

Після `npm run seed` у базі з'являється курс «Основи програмування мовою Python» з трьома модулями:

1. **Знайомство з Python** — що таке Python, встановлення, перша програма, змінні.
2. **Змінні та типи даних** — типи даних, функція `input()`.
3. **Умовні оператори** — `if`/`else`, `elif` та вкладені умови.

Кожен урок містить теоретичні блоки з прикладами коду та тест із поясненням правильних відповідей.

## Що НЕ реалізовано на цьому етапі (свідомо)

Авторизація користувачів, XP/streak/гейміфікація, онлайн-компілятор Python, AI-помічник та монетизація
винесені на наступні етапи (практика, переддипломна, дипломна робота) — див. `docs/architecture.md`.
Архітектура (папка `server/modules/` у плані розвитку) свідомо залишає місце для цих доменів без
переписування ядра.

## Скрипти

| Тека | Команда | Опис |
|---|---|---|
| `server` | `npm run dev` | Запуск API з автоперезапуском (nodemon) |
| `server` | `npm start` | Запуск API у звичайному режимі |
| `server` | `npm run seed` | Наповнення бази демонстраційним контентом |
| `client` | `npm run dev` | Запуск фронтенду в режимі розробки |
| `client` | `npm run build` | Продакшн-збірка фронтенду |
| `client` | `npm run preview` | Перегляд продакшн-збірки локально |
