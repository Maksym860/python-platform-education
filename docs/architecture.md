# Архітектура проєкту

## Загальна ідея

Платформа складається з двох окремих застосунків, що спілкуються через REST API:

- **client/** — фронтенд на React + Vite. Відповідає за інтерфейс: каталог модулів, сторінку уроку, тестування.
- **server/** — бекенд на Node.js + Express. Віддає навчальний контент з MongoDB через REST API.

```
Браузер учня
   │
   ▼
React SPA (client)  ──HTTP (fetch, /api/**)──▶  Express API (server)  ──Mongoose──▶  MongoDB
```

## Логічна структура навчального контенту

```
Course (курс)
 └── Module (модуль, напр. "Знайомство з Python")
      └── Lesson (урок)
           ├── Theory[] (теоретичні блоки з прикладами коду)
           ├── Practice (окремий блок практичних завдань "спробуй сам")
           └── Test (тест із питаннями)
```

## Модульність на майбутнє

Модель даних і структура папок навмисно розділені так, щоб надалі можна було додати нові домени
без переписування ядра: `users`, `gamification`, `challenges`, `code-runner`, `career`, `employers`,
`competitions`, `ai`. На етапі курсової роботи реалізовано лише `learning` (courses/modules/lessons/theory)
та `testing` (tests).

## Backend

- `app.js` — конфігурація Express-застосунку, підключення middleware та маршрутів.
- `server.js` — точка входу: підключення до MongoDB і запуск HTTP-сервера.
- `config/db.js` — підключення до MongoDB через Mongoose.
- `models/` — Mongoose-схеми: Course, Module, Lesson, Theory, Practice, Test.
- `controllers/` — бізнес-логіка обробки запитів.
- `routes/` — REST-маршрути, згруповані за ресурсами.
- `middleware/errorHandler.js` — обробка 404 та інших помилок.
- `seed/seed.js` — наповнення бази даних демонстраційним контентом (3 модулі, 7 уроків, 7 тестів).

## Frontend

- `src/pages/` — сторінки застосунку (Home, каталог модулів, модуль, урок, тест, результат).
- `src/components/` — переносні UI-компоненти (картки, блоки теорії, питання тесту тощо).
- `src/layouts/MainLayout.jsx` — спільний каркас із навігацією, футером та плавним переходом між сторінками.
- `src/services/api.js` — єдина точка звернення до REST API.
- `src/styles/global.css` — дизайн-система: кольори, типографіка, компоненти, анімації.
